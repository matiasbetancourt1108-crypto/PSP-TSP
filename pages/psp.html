Personal Software Process

El Personal Software Process (PSP) es una metodología de desarrollo de software desarrollada por Watts Humphrey en el SEI, que busca que cada profesional aplique disciplinas y métricas de forma individual.

¿Qué es el PSP?

El PSP se basa en la idea de que la calidad del software depende en gran medida de las habilidades y la disciplina del desarrollador. Para evitar la improvisación, dividió el desarrollo en fases claras que cada ingeniero debe seguir de forma personal y controlada.

El ciclo de vida

  • 1. Planificación del proyecto

    Se define el alcance, los tiempos y las actividades del desarrollo.

  • 2. Diseño

    Se diseñan las soluciones antes de escribir código.

  • 3. Implementación

    Se escribe el código cumpliendo los estándares definidos.

  • 4. Pruebas

    Se ejecutan pruebas para detectar y corregir defectos.

  • 5. Retroalimentación

    Se registra el proceso y se mejora el desarrollo personal.

Benefits of PSP

Control personal

El desarrollador controla su propio proceso, tiempo y calidad.

Mejora continua

Mediciones y revisiones permiten crecer como ingeniero.

Disciplina

Fases claras evitan el desarrollo descontrolado.
